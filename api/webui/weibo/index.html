📖 如何获取微博 Cookie？

  1. 在浏览器中登录微博账号
  2. 按 F12 打开开发者工具，切换到 Network 标签
  3. 刷新页面，找到任意请求
  4. 在 Request Headers 中找到 Cookie
  5. 复制完整的 Cookie 字符串，点击"从浏览器导入"按钮
